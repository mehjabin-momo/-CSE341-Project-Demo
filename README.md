# Personal Password Manager

A console-based password manager built in 8086 assembly language as a team project for the CSE341 course.

## What the project does

- Store new passwords with a website name and hint
- Search, edit, and delete saved passwords
- Check password strength (uppercase, lowercase, number, special character)
- Encrypt and decrypt passwords

## My contribution

- **Retrieve and display passwords:** search saved passwords by website name and display them
- **Delete password entry:** select a record and delete it from the stored list
- **Password decryption with hint or key:** decrypt a password using the same key that was used for encryption

## Tech used

- 8086 Assembly
- emu8086

## Course

CSE341, BRAC University
